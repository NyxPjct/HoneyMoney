# HoneyMoney 0.1.0 — first release (Phase 1 / MVP)

Free, open-source platform where AI agents help anyone create a digital product offer from scratch. No subscriptions, no in-app currency, no income promises.

## What's included

- **Account:** e-mail and password, Google sign-in (web), password recovery, 18+ confirmation.
- **Your own AI key** (Gemini, OpenAI or Claude) stored encrypted in Supabase Vault, or the instance's free model with a daily limit.
- **Offer from scratch:** a short briefing and six agents — Manager, Researcher, Strategist, Copywriter, Designer and Sentinel — produce the audience map, offer skeleton, full copy and sales page.
- **Sentinel review:** model review plus deterministic rules against income promises, health claims, guaranteed results, prohibited topics, incoherent prices and copied text. Nothing is published without its approval.
- **Animated 2D office** that mirrors each agent's real state in real time.
- **Projects** with version history, editable deliverables, "redo from here" and an optional review-each-step mode.
- **Block page editor** with live preview, publishing on its own subdomain with a strict CSP.
- **LGPD:** data export and account deletion; analytics only with consent.

## Downloads

HoneyMoney runs on a server (Next.js + Supabase + Inngest). The apps below open that server; on first launch they ask for its address. To run your own server, see the [installation guide](https://github.com/NyxPjct/HoneyMoney/blob/main/docs/installation.md).

| Platform | File | Notes |
| --- | --- | --- |
| Windows 10/11 (x64) | `HoneyMoney-0.1.0-win-x64.exe` | Not code-signed: SmartScreen may warn → *More info* → *Run anyway*. |
| macOS (Apple Silicon) | `HoneyMoney-0.1.0-mac-arm64.dmg` | Ad-hoc signed only: right-click the app → *Open* the first time. |
| macOS (Intel) | `HoneyMoney-0.1.0-mac-x64.dmg` | Same as above. |
| Linux (x64) | `HoneyMoney-0.1.0-linux-x86_64.AppImage` | `chmod +x` and run. |
| Android 7+ | `HoneyMoney-0.1.0-android.apk` | Installed outside the Play Store: allow "install unknown apps" when asked. |
| iPhone / iPad | — | Install from Safari: Share → *Add to Home Screen* (PWA). |
| Any browser | — | Chrome/Edge show an *Install app* button (PWA). |

Verify downloads with `SHA256SUMS.txt`.

## Known limitations

- Google sign-in does not work inside the desktop and Android apps (Google blocks sign-in in embedded browsers). Use e-mail and password there, or the web/PWA.
- The app interface is in Brazilian Portuguese; offers can be generated in Portuguese, Spanish or English.
- Phase 2 (reference catalog, ad creatives, e-book/PDF) and Phase 3 (community) are not included yet.
